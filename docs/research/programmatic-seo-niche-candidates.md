# Programmatic SEO niche candidates

**Scope:** Korea-first, no upfront spend, public data plus AdSense or affiliate revenue. Checked 2026-11-08. This is a feasibility shortlist, not a traffic or revenue forecast; search demand and competition were not measured.

| Candidate | Free-data fit | Monetization fit | Main risk |
|---|---|---|---|
| **Domestic trip finder by region and theme** (recommended) | Korea Tourism Organization (KTO) Korean Tour API lists about 260,000 items across 15 data types, including regional attractions, events, lodging, and pet-friendly travel. The portal says free, real-time, use scope unrestricted; development quota is 1,000 requests/day, and production access requires review. The API page says image rights vary by public-license type and includes image-use restrictions. [KTO API](https://www.data.go.kr/data/15101578/openapi.do) | Trip.com says its affiliate program has no partner fee, supports small individual sites, and pays commissions for bookings through affiliate links. Its current page advertises up to 7%; actual rates depend on program terms and booking type. [Trip.com FAQ](https://www.trip.com/partners/help/faq/account) · [Trip.com program](https://www.trip.com/partners/index) | API key and production review; image-by-image rights; travel-data pages need original planning value beyond copied API descriptions. |
| **Pet-friendly domestic trips** (narrower variant of the first) | Same KTO API explicitly includes pet-friendly travel information, so it can be a filter/landing-page dimension without adding a second source. [KTO API](https://www.data.go.kr/data/15101578/openapi.do) | Same no-fee Trip.com partner path; Coupang Partners could fit travel gear, but its fee/eligibility terms were not verified here. [Trip.com FAQ](https://www.trip.com/partners/help/faq/account) · [Coupang Partners](https://partners.coupang.com/) | Pet-friendly lodging inventory and the number of usable KTO records were not sampled. Do not promise that a Trip.com listing accepts pets without confirming it. |
| **EV charging station finder** | KEPCO's data.go.kr entry describes a live station-operations API, requires a KEPCO data-portal account and API key, and lists the license as unrestricted. The portal's accessible metadata did not confirm a no-cost operating quota, so verify that before choosing it. [KEPCO API](https://www.data.go.kr/data/15147132/openapi.do) | AdSense after site review, or product links for EV accessories through a general affiliate program. Google's setup guidance requires a live site with enough content and a policy review; the fee-free affiliate terms for EV products were not verified. [AdSense setup](https://support.google.com/adsense/answer/7402256?hl=en) | Data access/cost and freshness need confirmation; direct product fit is weaker than travel bookings. |

## Recommendation

Start with **domestic trip discovery by region**, then add pet-friendly filters only if the API sample contains enough usable records. This gives one official source and a directly related, explicitly no-fee affiliate path. Prototype with a small curated set of useful pages before generating more URLs. Do not treat raw API records or keyword-swapped templates as finished content: Google defines scaled content abuse as mass page creation primarily to manipulate rankings, and thin affiliation includes copied merchant material without added value. [Google Search spam policies](https://developers.google.com/search/docs/essentials/spam-policies)

## Limits to the zero-spend claim

The KTO API and Trip.com affiliate program are explicitly free to use according to their official pages. This does not establish that hosting, a custom domain, tax/payment setup, or future API traffic will remain free. AdSense approval is separate and not guaranteed. The next evidence check, after choosing the niche, is a small KTO API sample and a test of the free hosting/domain path.
